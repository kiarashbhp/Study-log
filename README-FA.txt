دفتر گزارش کار مطالعه - نسخه ۲

ویژگی‌ها:
- تاریخ شمسی و ساعت ۲۴ ساعته
- ثبت چند جلسه برای یک درس و مبحث در بازه‌های جدا
- ثبت چند نوع فعالیت در هر جلسه همراه با مدت هرکدام (کتاب، جزوه، ویدئو، مرور و حل تمرین)
- ثبت زمان تست‌زنی، تعداد تست، غلط و سؤال تشریحی به تفکیک جلسه
- ادغام خودکار جلسه‌های یک درس/مبحث در گزارش نهایی
- بخش اختیاری مرور و روتین شبانه؛ امکان ثبت تست روتین مثل ریاضی یا تقطیع
- محاسبه مجموع زمان روز با احتساب زمان تست‌زنی و مرور
- آرشیو، آمار هفتگی، حالت روشن/تاریک و پشتیبان‌گیری/بازیابی JSON
- ذخیره محلی و پشتیبانی آفلاین پس از بارگذاری اولیه

نصب روی GitHub Pages:
۱) فایل ZIP را استخراج کن.
۲) تمام فایل‌های داخل ZIP را در ریشه مخزن GitHub بارگذاری و Commit کن.
۳) اگر قبلاً PWA نصب کرده‌ای، سایت را یک‌بار با اینترنت باز کن تا Service Worker نسخه جدید را دریافت کند. در صورت نمایش نسخه قدیمی، داده‌ها را پاک نکن؛ صفحه را دوباره بارگذاری کن و کمی صبر کن.

نکته داده‌ها:
اطلاعات نسخه قبلی با کلید ذخیره‌سازی قبلی در اولین اجرا خوانده می‌شود و به ساختار جدید منتقل می‌شود. با این حال قبل از جایگزینی فایل‌های سایت، از بخش «پشتیبان» یک فایل JSON بگیر.
